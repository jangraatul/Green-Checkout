# Green Checkout – Eco-Coin Grove

🌿 **Green Checkout** is an eco-friendly shopping web application that promotes sustainable shopping through carbon-offset contributions and an Eco-Coin reward system.

## ✨ Features

- Browse and search eco-friendly products.
- Filter products by categories.
- Add custom products to the cart.
- Manage cart items and quantities.
- Contribute towards carbon-neutral delivery.
- Earn and redeem Eco-Coins on purchases.
- Track CO₂ offset and virtual tree growth.
- View order receipts and activity history.
- Responsive and interactive user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open the project folder.
3. Run `index.html` in your web browser.

No additional installations or dependencies are required.

## ⚠️ Note

This is a front-end demonstration project. Checkout is simulated, and application data resets on page refresh. CO₂ offset calculations are illustrative and do not represent verified environmental impact.

## 🎯 Objective

To encourage sustainable shopping by combining e-commerce features with environmental awareness, reward-based incentives, and carbon-offset contributions.
